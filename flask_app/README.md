# Basic Flask api

A simple flask application in understanding workings of api and data sharing through api endpoint.

## Prerequisites

**Runtime Environments:** Python 3.10+

**Package Managers:** pip

**Terminal:** bash

**OS:** windows

## Test commands

Open bash terminal and cd to the project directory and run below commands.

```
pip -m venv venv
```

```
source venv/Scripts/activate
```

```
pip install -r requirements.txt
```

```
flask run
```
